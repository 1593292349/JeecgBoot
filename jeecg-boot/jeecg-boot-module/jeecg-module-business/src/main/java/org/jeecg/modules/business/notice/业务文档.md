# 通知管理

## 业务需求

### 1.通知发布

#### 操作

- 新增：打开`新增通知弹窗`

#### 新增通知弹窗

**字段**

- 标题：文本
- 内容：富文本
- 通知类型：字典（全部、指定部门、指定人）
- 通知范围
  - `通知类型`=指定部门：多选部门
  - `通知类型`=指定人：多选人
- 发布者：自动填充，当前用户
- 定时发布：字典（是、否）
- 发布时间
  - `定时发布`=是：选日期时间

**操作**

- `发布`按钮
  - 显示条件：`定时发布`=否
  - 执行功能：保存为`已发布`
- `保存`按钮
  - 显示条件：`定时发布`=是
  - 执行功能：保存为`待发布`，并执行定时任务

#### 通知详情弹窗

**字段**

- 编号：发布时后端生成，格式`20260728001`（年月日+当天序号）
- 标题
- 内容
- 通知类型
- 通知范围
- 发布者
- 发布时间：实际发布时间

#### 列表

- 编号
- 标题
- 通知类型
- 通知范围
- 发布者
- 发布时间：实际发布时间
- 状态：字典（待发布、已发布）
- 操作
  - `详情`按钮
    - 显示条件：`状态`=已发布
    - 执行功能：打开`通知详情弹窗`
  - `编辑`按钮
    - 显示条件：`状态`=待发布
    - 执行功能：打开`新增通知弹窗`并填充数据
  - `删除`按钮
    - `状态`=待发布：直接删除
    - `状态`=已发布：逻辑删除

### 2.通知中心

#### 列表

> 显示数据：`状态`=已发布 & 当前用户在`通知范围`中

- 编号
- 标题
- 通知类型
- 通知范围
- 发布者
- 发布时间：实际发布时间
- 操作
  - `详情`按钮：打开`通知详情弹窗`


## 数据库设计

### 1. 建表语句

```sql
CREATE TABLE "safety_security_examine_main"
(
    "id"                   VARCHAR(36)  NOT NULL COMMENT '主键',
    "create_by"            VARCHAR(50)    DEFAULT NULL COMMENT '创建人',
    "create_time"          TIMESTAMP      DEFAULT NULL COMMENT '创建日期',
    "update_by"            VARCHAR(50)    DEFAULT NULL COMMENT '更新人',
    "update_time"          TIMESTAMP      DEFAULT NULL COMMENT '更新日期',
    "sys_org_code"         VARCHAR(64)    DEFAULT NULL COMMENT '创建部门',

    "source"               VARCHAR(255)   DEFAULT NULL COMMENT '考核来源',
    "matter"               VARCHAR(255) NOT NULL COMMENT '考核事项',
    "examine_time"         TIMESTAMP    NOT NULL COMMENT '考核时间',
    "examiner_id"          VARCHAR(64)  NOT NULL COMMENT '考核人, 表 sys_user',
    "level"                VARCHAR(64)  NOT NULL COMMENT '考核级别, 字典 dict_examine_level',
    "category"             VARCHAR(64)  NOT NULL COMMENT '考核类别, 字典 dict_examine_category',
    "accident_item"        VARCHAR(64)    DEFAULT NULL COMMENT '考核对应项-事故, 字典 dict_examine_item_accident',
    "violation_item"       VARCHAR(64)    DEFAULT NULL COMMENT '考核对应项-违规, 字典 dict_examine_item_violation',
    "other_item"           VARCHAR(255)   DEFAULT NULL COMMENT '考核对应项-其他, 文本',
    "reward_standard"      VARCHAR(255)   DEFAULT NULL COMMENT '奖惩标准, 字典 dict_examine_reward_standard',
    "document_info"        VARCHAR(255)   DEFAULT NULL COMMENT '发文名称及文号',
    "standard_detail"      VARCHAR(2000)  DEFAULT NULL COMMENT '标准明细',
    "depart_id"            VARCHAR(64)  NOT NULL COMMENT '单位, 表 sys_depart',
    "unit_penalty_amount"  DECIMAL(20, 2) DEFAULT NULL COMMENT '单位扣罚金额',
    "unit_score_deduction" DECIMAL(20, 2) DEFAULT NULL COMMENT '单位积分扣除',
    "remark"               VARCHAR(2000)  DEFAULT NULL COMMENT '备注',
    "bpm_process_id"       VARCHAR(64)    DEFAULT NULL COMMENT '流程id',
    "process_status"       VARCHAR(64)  NOT NULL COMMENT '流程状态, 字典 dict_examine_status',
    "approved_time"        TIMESTAMP      DEFAULT NULL COMMENT '审核通过时间',

    PRIMARY KEY ("id")
);
COMMENT
ON TABLE "safety_security_examine_main" IS '过程安全考核';
```

## 后端接口设计

### 模块一：过程安全考核（ExamineMain）

#### 1.1. 分页列表查询

**接口路径**：`GET /securityExamine/main/list`

**权限**：无需权限

**入参**：

| 字段       | 类型      | 必填 | 说明        |
|----------|---------|----|-----------|
| pageNo   | Integer | 否  | 页码，默认1    |
| pageSize | Integer | 否  | 每页条数，默认10 |

支持主表 `safety_security_examine_main` 实体字段作为查询条件（如 `source`、`matter`、`category`、`level`、`processStatus` 等）。

**出参**：`Result<IPage<ExamineMainVo>>`

**业务逻辑**：

1. 分页查询主表 `safety_security_examine_main`
2. 查询每条主表对应的子表记录数作为 `人员数量`
3. 组装 `ExamineMainVo` 返回

**ExamineMainVo**：

| 字段                 | 类型         | 说明            |
|--------------------|------------|---------------|
| id                 | String     | 主键            |
| source             | String     | 考核来源          |
| matter             | String     | 考核事项          |
| examineTime        | Date       | 考核时间          |
| examinerId         | String     | 考核人id（@Dict）  |
| level              | String     | 考核级别（字典值）     |
| category           | String     | 考核类别（字典值）     |
| accidentItem       | String     | 考核对应项-事故（字典值） |
| violationItem      | String     | 考核对应项-违规（字典值） |
| otherItem          | String     | 考核对应项-其他      |
| departId           | String     | 单位id（@Dict）   |
| unitPenaltyAmount  | BigDecimal | 单位扣罚金额        |
| unitScoreDeduction | BigDecimal | 单位积分扣除        |
| processStatus      | String     | 流程状态（字典值）     |
| personnelCount     | Integer    | 人员数量（子表行数）    |
